## How to Use This Pack

### For Sales Team

1. **Qualify Prospects:**
   - Use Design Partner Program eligibility criteria
   - Target: Healthcare (CMIO, clinical operations) OR FSI (CCO, Head of AML/KYC)
   - Ideal: Mid-to-large enterprise with active AI/automation initiative

2. **Discovery Call:**
   - Use ROI Mini-Deck (Slides 1-3) to frame problem + solution
   - Map pain points to proof bundle (documentation burden → Healthcare; compliance workload → FSI)
   - Discuss success criteria + KPIs (align on what "good" looks like)

3. **Proposal:**
   - Send proof bundle charter + pilot SOW within 48 hours of discovery call
   - Include: Pricing, timeline, phase gates, SLAs
   - Provide: SOC 2 Type II executive summary, BAA/DPA template, security questionnaire

4. **Close:**
   - Execute contracts (MSA, SOW, BAA/DPA)
   - Hand off to delivery pod for kick-off (Week 0)

### For Delivery Pods

1. **Pre-Kick-Off (Week 0):**
   - Review proof bundle charter + pilot SOW
   - Complete security review with customer IT
   - Provision user accounts + set up collaboration channel (Slack/Teams)

2. **Execute (Weeks 1-12):**
   - Follow 12-week execution workbook
   - Track KPIs weekly (use status report template)
   - Conduct phase gate reviews (Weeks 4, 8, 12)

3. **Support:**
   - Use operator runbooks for pilot participant training
   - Provide T1/T2/T3 support per SLAs in pilot SOW
   - Conduct weekly steering committee meetings

### For Product/Engineering

1. **Reuse Components:**
   - Decision-gate engine: Leverage `DataManagement/governance_framework.py` + `DataManagement/safety_gates.py`
   - Audit trails: Extend `DataManagement/double_helix_sissa_integration.py`
   - Operator workflows: Base on `docs/OPERATOR_RUNBOOK.md` patterns

2. **Customize Per Vertical:**
   - Healthcare: ASR integration, SOAP note templates, EHR export formats
   - FSI: Transaction monitoring data ingestion, RAG corpus (FinCEN guidance, historical cases), SAR filing XML

3. **Monitor KPIs:**
   - Instrument dashboard with KPI tracking (accuracy, latency, uptime, CSAT)
   - Weekly reports to delivery pod lead
